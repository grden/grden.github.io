As a team of 6, we built Palmful, an AI-based bouquet design and archiving web service to address the limitations of uniformity and ephemerality in flower gifting.

You can see the full source code of the project at <ArrowLink href="https://github.com/ganadiiiii" className="font-normal">GitHub</ArrowLink>.

<br/>

## Problem Definition
Through desk research and a user survey involving 100 participants, 
we identified the key pain points in the flower gifting experience.

By learning Color Theory, Seasonality, and Floriography, we built a "Rule-based Logic" pipeline that filters out logically inconsistent combinations before the AI generation process.

- Project Management: Defined problems via desk & user research, designed IA/User Flow, and gave final presentation.

- Figma Design: Designed key features including the Archiving page, Friend tab, and Design Result page.
- Interaction Design: Implemented interactions using Framer-motion and GSAP.
