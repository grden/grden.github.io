To address the issue of YouTube's recommendation system diverting users from their initial goals, I developed Filca, a Chrome extension that filters video feeds according to user selected categories.  
I also conducted a quantitative analysis of user logs to not only evaluate the extension's effectiveness, but also derive design implications for YoutTube's recommendation system.

You can check out <ArrowLink href="https://chromewebstore.google.com/detail/dmgbijacfoechdplahccjjhjkhhldpcd?utm_source=item-share-cb" className="font-normal">Filca on the Chrome Web Store</ArrowLink>.

<br/>

## Background

I was frustrated with how easily I'd get distracted. I'd go to YouTube to find a lecture or tutorial, and end up watching game videos or random comedy skits for an hour.
While YouTube's category chips offer some filtering, they don't persist across sessions, lack customization, and often miss the category I need.

<br/>

## Solution

To address this, I developed a Chrome extension that filters video feeds according to user selected categories.

I did:
- Design and development of a Chrome extension using React and TypeScript.
- Implementation of a FastAPI server on AWS EC2 to identify the most semantically similar category, using OpenAPI's embedding model.

<br/>

## Features

Filca allows users to save preferred categories, auto-apply them on each visit, and intelligently match to the closest category.

## Next Step: Data Analysis

I collected 5000+ usage logs from 46 users over 24 days period via Firebase to analyze user patterns on YouTube and evaluate the extension’s effectiveness.

<p className="text-center text-gray-500">Usage logs</p>

Based on this, I tried to investigate the following research questions.

**RQ1. Can we predict a user's intent of visiting YouTube (Utilitarian vs. Hedonic) based on temporal context?**  
**RQ2. Will filtering the recommendation system based on the user's intent of visiting YouTube improve engagement?**

## Discussion
**1. Effectiveness of the Extension**

Filca successfully extended session durations by aligning content with users' practical goals.
This validates that relevance drives sustained engagement.

<div className="mx-auto h-2"/>

**2. Design Implications for YouTube's Recommendation System**

Based on the results, I proposed two design goals for YouTube's recommendation system.

<section className="grid grid-cols-2 w-full mx-auto gap-4 md:gap-16">
    <div>
        **"Quality of Time" over "Time Spent"**
        <p className="text-gray-500">Recommendation systems should prioritize fulfilling the user's purpose of visit over retention.<br/>Deep engagement in goal-oriented sessions proves that satisfying the user's purpose is a more sustainable metric.</p>
    </div>
    <div>
        **Leverage External Context**
        <p className="text-gray-500">Recommendation systems should proactively adjust feeds based on external contexts (e.g., time, day) to reduce cognitive load and support user autonomy.</p>
    </div>
</section>
